# Telegram AI Bot

Бот для:
- считывания комментариев Telegram-канала;
- AI-анализа комментариев;
- определения темы обучения;
- отправки горячих лидов в amoCRM.

## Установка

1. Создайте Telegram-бота через BotFather
2. Добавьте бота в группу обсуждений
3. Отключите Privacy Mode
4. Загрузите проект в GitHub
5. Подключите Railway
6. Настройте webhook

## Файлы проекта

- app.py — основной сервер Flask
- requirements.txt — зависимости Python
- README.md — инструкция проекта

## Webhook

Формат webhook:

https://your-domain.com/webhook

## Запуск

Railway автоматически установит зависимости и запустит сервер.

## Проверка

После запуска:
- откройте URL Railway;
- отправьте комментарий в Telegram;
- проверьте Logs в Railway.
